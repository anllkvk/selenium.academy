# 📝 El Notlarım

Bu klasör, ders sırasında **kağıda elle aldığım notların** dijital karşılığı için.

## Nasıl kullanırım?
- Kağıttaki notumun **fotoğrafını** çekip buraya at (örn. `ders-02-locators.jpg`).
- İstersen elle aldığın notu buraya **yazıya da dökebilirsin** (örn. `ders-02-locators.md`).
- Dosya adını `ders-XX-konu` düzeninde tut, sonradan kolay bulursun.

## Önerilen isimlendirme
```
notlar/
├── ders-01-kurulum.jpg
├── ders-02-locators.jpg
├── ders-03-cookies.md
└── ...
```

> İpucu: Fotoğrafları küçük tutarsan (telefon galerisinden "paylaş > boyut küçült")
> repo şişmez. Çok sayıda büyük fotoğraf birikirse bana söyle, ayrı çözüm kurarız.
